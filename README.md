# CLIMAEXPRESS

🌦️ API de Consulta del Tiempo Inteligente ☁️🧠
¡Bienvenido a la API de Consulta del Tiempo Inteligente! Este proyecto permite introducir un ciudad y obtener una respuesta clara con los datos del clima más relevantes.

✨ Características Principales
Cobertura global: Compatible con ciudades de todo el mundo.

Campos consultables:

temperatura

descripción

viento

dirección del viento

presión atmosférica
